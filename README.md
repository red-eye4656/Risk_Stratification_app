# Risk_Stratification_app# 🏥 Risk Stratification App

A Machine Learning-based web application that predicts whether a patient is at **High Risk** or **Low Risk** using clinical features such as **Age**, **Length of Stay**, and **Treatment Cost**.

## 🚀 Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## ▶️ Run the App

```bash
streamlit run risk_predict.py
```

Built to demonstrate the end-to-end Machine Learning workflow, including data preprocessing, model training, and deployment using Streamlit.
